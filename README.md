Description

KeenKeeper Pro is a modern React web application designed to help users maintain meaningful relationships by tracking and managing their interactions with friends. It provides an intuitive interface to log calls, texts, and video chats while offering insights through a visual timeline and analytics dashboard.

🛠️ Technologies Used
React.js (Hooks)
JavaScript (ES6+)
Tailwind CSS
✨ Key Features
📊 Interaction Tracking
Easily log and monitor calls, text messages, and video interactions with friends.
📅 Timeline with Filters
View interaction history and filter by type (All, Call, Text, Video).
📈 Analytics Dashboard
Visual breakdown of interaction data with percentage-based insights.
